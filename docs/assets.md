**Font packages**: `@fontsource-variable/newsreader` (Newsreader), `@fontsource-variable/manrope` (Manrope), `@fontsource/hind-siliguri` (Hind Siliguri), `@fontsource/noto-serif-bengali` (Noto Serif Bengali). Each selected Fontsource distribution is intended for locally hosted font loading; verify its actual license file and loaded subsets after `pnpm install`. Do not send font binaries to third parties and do not substitute a Google-hosted font request for the local files. All fonts used for C04 are text assets, not rasterized wordmarks.

**Before live content**: Owner supplies official high-resolution logos, rights-cleared real photography/graphics, real project and evidence approvals, team consent, a real edition cover/price/stock/preview authorization, academy offerings and official policies. C04 deliberately invents none of those.
